GitHub PR: show only one file extension
A userscript that adds an only button to each extension in the file filter menu of a pull request's changed files, so you don't have to untick the others one by one.

Install
Install Tampermonkey.
In Chrome, open chrome://extensions, then Tampermonkey > Details, and turn on Allow User Scripts (on older versions, turn on Developer mode).
Add github-pr-extension-filter.user.js as a new script.
Use
Open the file filter menu on a PR and click only next to an extension. To see all files again, use Clear filters or remove file-filters from the address.
